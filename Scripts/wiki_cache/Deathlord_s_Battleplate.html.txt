<p><b>Deathlord's Battlegear</b> is the <a href="/wiki/Class_Hall" title="Class Hall">Class Hall</a> set for <a href="/wiki/Death_Knights" class="mw-redirect" title="Death Knights">Death Knights</a>.  Visually it's a recolor of <a href="/wiki/World_of_Warcraft:_Mists_of_Pandaria" title="Mists of Pandaria"><img alt="Mists of Pandaria" src="/images/Mists-Logo-Small.png?f96b23" decoding="async" loading="lazy" width="46" height="14" style="vertical-align: middle" data-file-width="46" data-file-height="14" /></a><a href="/wiki/Golden_Chest_of_the_Lich_Lord" title="Golden Chest of the Lich Lord">Lich Lord Armor</a>, and is meant as an entry level set as <a href="/wiki/Tier_19" title="Tier 19">Tier 19</a> is item level 850 in normal mode. A Full set can be seen standing behind <a href="/wiki/Quartermaster_Ozorg" title="Quartermaster Ozorg">Quartermaster Ozorg</a>.
</p>
